SQL + JavaScript SQLite in the browser

Type one or more SQL statements below and click Run. All queries run against an in-memory SQLite database in your browser.

🎓 Try: SELECT * FROM students;
Tip: You can run multiple statements at once (they’re processed in order).

How this ties into JavaScript

Under the hood, the browser is running SQLite via WebAssembly. Your JavaScript code:

  • Creates the database object: const db = new SQL.Database();
  • Executes SQL with db.exec(sql)
  • Reads the result rows and builds an HTML table dynamically.

Try this with students:

  • Have them add a new student using INSERT.
  • Filter rows: SELECT * FROM students WHERE grade >= 80;
  • Sort: ORDER BY grade DESC;
  • Compute a class average using AVG(grade).

Keyboard tips

  • Use Ctrl + A → Delete to clear.
  • Use Ctrl + Z to undo changes in the SQL box.

Ideas for assignments

  • “Movie library” with title, year, and rating.
  • “Course enrollment” with students, courses, enrolments.
  • “Inventory” for a small store, with quantities and prices.
